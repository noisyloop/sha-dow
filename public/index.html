    About /01/

    A 24-hour board where every post is shown as binary. No accounts, no email, no phone number, no attachments. Your name is an emoji.

    Inspired by Shadow, a research protocol with no phone number and no central identity. Planned next: end-to-end encrypted 1:1 rooms.

    Install sha-dow

    Install the board as an app: its own window and icon, nothing to download.

    • iPhone / iPad (Safari): Share → Add to Home Screen
    • Mac (Safari): File → Add to Dock
    • Chrome / Edge: the install icon at the right of the address bar, or menu → Install sha-dow
    • Android (Chrome): menu ⋮ → Install app
    • Firefox: not supported on desktop yet; use one of the browsers above.
